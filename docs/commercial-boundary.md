# 商业模块边界

依据 E01、E07。只登记入口及隔离原则，不拆解转化路径。

| 模块 | 页面观察 | 处理方式 |
|---|---|---|
| 套餐与权益 | 版本、有效期、可授权店铺、立即升级 | 独立计费/权益上下文；未进入升级流程 |
| AI 计费 | AI豆余额、充值、消费记录 | 独立额度接口；未生成、扣费或充值 |
| 推广返佣 | 推广合作、佣金、推广人数、邀请码 | 独立推广域；未拆邀请与结算 |
| 营销入口 | 顶部营销、首页营销推广概览 | 本轮排除营销与广告转化拆解 |
| 外部平台招商 | 首页外部平台入口 | 不跟进注册和招商转化 |

系统设计建议（inferred）：核心业务只依赖抽象的权限/额度检查结果；金额、充值订单、返佣及权益计算由独立模块负责。额度不足应产生可恢复的业务错误，不能与商品发布成功混为一个状态。

商品刊登和订单履约保留为核心 ERP 业务；这里排除的是收费、拉新、返佣和营销转化流程。
