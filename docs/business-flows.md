日期：2026-11-05（Asia/Shanghai）。工具：Tabbit CLI；来源为已登录网页。observed 表示页面内容/控件已观察；inferred 表示由页面反推；unverified 表示未执行验证。

## 选品运营：从货源到店铺商品

前置：具有登录权限；发布还需要已授权店铺和平台配置，后者未执行验证。

采集上架配置提供“仅采集”“统一自动上架”“采集时选择目标”三种模式；“仅采集”的说明明确指出不会自动创建上架工作流（E10，observed）。因此不能把所有采集动作都推断为立即刊登。配置还包含语言、无库存/重复/预售过滤、1688价格和图片过滤、AI核价开关。本轮只读取配置，没有切换或保存。

1. 进入产品 → 选品中心 → 选品采集。页面提供插件、链接、关键词、导入、1688、PDD、海外榜单入口（E02，observed）。只阅读插件流程，没有安装插件或抓取货源。
2. 页面说明采集结果可进入选品库或直接发布；选品库的四步引导是采集、核对、认领、AI自动化刊登（E02、E03，observed 文案）。这些分支的实际写入结果为 unverified。
3. 进入选品库，按来源、采集人、核对状态、自动刊登状态、AI核价状态、标签和时间查找商品。核对商品信息、货源价格、SKU、尺寸重量。待认领、已认领、已上架、AI核价是页面分组（E03）。
4. 认领工作流绑定目标平台/店铺；页面说明按平台规则与认领配置加工资料后刊登。平台提示包含 Shopee、Tiktok、Mercado、Ozon、Amazon（E03）。未将该列表等同于所有平台能力完全一致。
5. 进入上架工作流查看任务进度和当前节点；页面状态包含排队中、运行中、待发布、发布中、已完成、已暂停、异常及全部（E04）。具体节点、重试规则和发布回执待验证。

异常设计建议：缺失尺寸/重量或成本时返回资料核对；平台授权失效时等待重新授权；任务失败保留输入与错误节点；发布结果不明先查询平台回执，避免重复刊登。均为 inferred，不能写成网站已具备的行为。

## 商品运营：存量商品诊断与优化

产品 → 优化工作流 → Shopee。页面将店铺商品状态（在售中、已售罄、审核中、未上架、被禁售、已删除、平台已删除）与优化任务状态（待调度、运行中、已暂停、已完成、失败、待发布）分别展示（E05）。

用户可按店铺、销量、发货时效、标题、时间、类目、尺码表、优化状态、更新状态及视频筛选。页面提供批量同步、批量优化、批量暂停、批量继续、批量发布、加入选品库等入口。未执行这些写操作。

推荐流程（inferred）：同步平台快照 → 诊断 → 选择优化范围 → 异步加工 → 人工复核 → 发布更新 → 同步确认。页面显示入口与状态，不足以证明所有迁移顺序。

## 内容运营：AI 创作

AI创作页面有图片创作、视频创作、POD定制；图片创作下有AI生图、图片处理、商品文案，支持白底主图、卖点图、商品详情图、组合套图及历史任务入口（E07）。页面还出现语言、比例、数量控件。

建议把生成任务、素材和商品建立关联，再复用到工作流。未点击生成；输出质量、模型种类、计费及生成结果回写未验证。充值入口单独隔离。

## 订单专员：履约处理

订单 → 订单处理（E06）。可按平台、店铺、订单状态、站点、备注/标记、订单编号和下单时间检索。

页面队列：待处理、待打单、待揽收、已交运、已搁置、已取消、全部。页面操作：安排发货、获取运单号、批量打印、批量采购、自动采购、同步、导入、导出。

推荐主流程（inferred）：同步订单 → 待处理核查 → 安排发货/获取运单号 → 待打单打印 → 待揽收交接 → 已交运；已搁置与已取消作为分支。是否允许跨队列操作、取消的可逆性、拆合单、库存预占、采购与履约先后关系尚未验证。

## 经营者：复盘与口径

店铺统计按平台、店铺分组及店铺筛选，提供今日实时、前7天、前30天、有效订单数/有效销售额及环比（E08）。订单统计按日期汇总，展示有效销售额、有效订单数、总销售额、总订单数、取消订单数和统计时间（E09）。

工作台另有平台、统计周期和订单口径选择（E01）。不要直接把总订单数等同于有效订单数；当前尚未验证有效订单的完整排除规则、退款处理、时区切日、汇率和延迟。建议指标模型显式保存口径版本、币种、窗口及同步时间。
